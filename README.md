# Consulta Completas Web V6

Ajustes:
- pré-contagem somente ao clicar em `Calcular quantidade`;
- sem saldo disponível, a pré-contagem é bloqueada e aparece aviso;
- CEP disponível na exportação tanto na base Atualizados 2026 quanto na base detalhada;
- CEP, Bairro e DDD não entram na pré-contagem;
- aviso de pré-contagem mais destacado;
- correção do seletor múltiplo: após selecionar uma opção, o menu continua utilizável para adicionar outras;
- cliente pode escolher um nome para o Excel;
- o sistema acrescenta quantidade + data/hora/milissegundos ao nome para evitar colisão;
- botão `Limpar filtros` mais destacado;
- histórico continua permitindo baixar pedidos concluídos.

Publique o servidor V6 primeiro e depois use o agente V6.
